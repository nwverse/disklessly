# Pake GUI

The management page is `Sources/isenough/web`. Build a tray/window wrapper with Pake against
`http://127.0.0.1:47256/ui/` (requires the local `isenough serve` service). Pake is GPL-3.0;
review licensing before distributing a generated wrapper. It is a tray/window UI, not a native
Dock-less macOS menu-bar extra.
